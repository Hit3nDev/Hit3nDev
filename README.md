### 📐 How I work

- **Measure before claiming.** If a README has a number, there's a script or report behind it.
- **Report what didn't work.** BM25 beat my dense retriever on SciFact — so the README says so, and explains why.
- **No leakage, no shortcuts.** Preprocessing inside the pipeline, model chosen by cross‑validation, test set touched once.
- **Make it usable by non‑experts.** A shop owner should get a sentence, not a leaderboard.
